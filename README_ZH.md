## 关于项目
**Magical Land** 是一款 Minecraft Java 版模组，可以将玩家和生物变成 MLP 世界观的小马模型

## 愿景
- 以尽量还原且精美的方式将 MLP 角色引入 Minecraft
- 在可能的情况下，通过模型、纹理、动画和附加机制来扩展该模组  
- 构建一个粉丝和开发者都能享受、学习和改进的项目  

## 招募合作者
**模型资产**是该项目的基础，但项目的诞生也离不开强大的编程支持
我们正在寻找对 MLP 和 Minecraft 有着共同热爱的长期合作者，能在以下方面提供帮助：
- 共同开发这个模组
- 可选：开发自定义机制以丰富游戏玩法  

这主要是一个出于热爱的项目。我目前还不知道它是否能产生收益，因此主要目标是共同创造一些有意义的事物。我也希望通过这个项目，我们能够结下真挚的友谊，互相学习，作为创作者共同成长。
