# Magical Land  
A Minecraft Project that turns players and mobs into ponies

## About the Project
---
**Magical Land** is a Minecraft mod for Java Edition that introduces ponies and related content from the television series "My Little Pony".  

## Vision
---
- Introduce pony characters into Minecraft in a faithful and polished way  
- Expand the mod with models, textures, animations, and additional mechanics where possible  
- Build a project that can be enjoyed, studied, and improved by fans and developers alike  

## Looking for Collaborators
---
The **artwork and creative assets** are the foundation of this project, but it cannot be completed without strong programming support.  
We are seeking long-term collaborators who share a passion for both ponies and Minecraft and can assist with:
- Editing Java programmes and problem-solving in the mod development process
- Entity behaviour and animation controllers
- Optional: developing custom mechanics to enhance gameplay  

This is primarily a passion project. I do not know yet whether it could generate revenue, so the main goal is to create something meaningful together. I also hope that through this project we can form genuine friendships, learn from one another, and grow together as creators.
