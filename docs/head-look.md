# 头部视角跟随

头部采用原版玩家的头身相对偏航与视角俯仰输入。`PonyHeadLookMath` 在前后 tick 之间插值，跨越 ±180° 时走短路径；`PonyRenderer` 在动作动画求值之后、Head 递归绘制前叠加旋转，离开作用域恢复原角度及 Gecko 状态标记。

- 普通姿态：左右最多 70°、上下最多 45°，避免小马颈部在极端角度明显断开。
- 游泳：减弱响应，限制在左右 40°、上下 25°。
- 滑翔、激流和冲刺飞行：进一步减弱，限制在左右 35°、上下 25°。
- 睡眠：不叠加头转，保留原动作姿态。
- 仅世界角色启用；主预览和固定缩略图不随现实玩家视角转动。

后退单独使用 `PonyBackwardLook` 时间线：连续后退 1 秒后才回头，用 0.275 秒缓入缓出旋转；停止后退同样用 0.275 秒恢复，短按会重新计时，不提前调用“向后看”表情。转动与恢复速度是上一版的两倍，等待时长不变。远端继续使用已有 `backward_walk` 动作同步，各玩家独立计时，不增加协议。

`PonyBackwardHeadPose` 在世界绘制期间成对覆盖 Neck、Head：等待时移除原后退动画提前回头的部分，转动使用四元数短路径插值，完成后固定在作者 `backward_walk` 第 0 帧姿态，不再叠加视角或周期性头颈摆动。返回时避开主控制器最初 3 tick 中尚未消失的旧回头轨道，再用剩余 2.5 tick 完整衔接当前动作和视角，避免缩短时间后在末尾跳变。四肢、身体动作和全部原动画资产保持不变；退出绘制作用域恢复两个骨骼的原角度和状态标记。

不修改模型、UV、贴图、动画资产或自追踪眼仁算法。普通状态头只跟随玩家视角，不主动扭向眼仁关注的实体；回头沿用作者已有锁定眼神，等待期间仍使用正常眼神。眼仁原有完整局部矩阵求逆自然考虑头部实际旋转，不能再手工扣一次 headYaw。摄像机、预览和缩略图不受此后退覆盖影响。

`PonyHeadLookTest` 覆盖原视角插值和恢复；`PonyBackwardLookTest` 覆盖 1 秒延迟、0.275 秒过渡、表情时序、双端相对计时、作者姿态一致、锁定期间相机和动画扰动无效、中断/短按、退场末端连续、成对恢复和跨玩家隔离。仍需游戏验收大角度发型与头颈接缝。
