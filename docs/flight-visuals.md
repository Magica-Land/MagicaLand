# 飞行姿态

外观包按角色当前的翅膀、角配置选择飞行表现：

| 外观配置 | 飞行表现 |
| --- | --- |
| 有翅膀 | 沿用拍翼与高速飞行动画，包括有翼的天角兽、幻形族 |
| 无翅膀、无角 | 身体保持直立悬浮，四肢采用现有起飞姿势 |
| 无翅膀、有角 | 直立悬浮，角先亮起，随后出现流动的包身光 |

此功能属于外观表现。飞行权限、速度、碰撞与能力消耗仍由原版或玩法 Addon 决定。

## 姿态与惯性

扩展可通过 [API 1.5 的飞行活动注册](appearance-api.md#独立飞行表现)启用这套表现。原版飞行和扩展飞行共用姿态、惯性与魔法效果；注册本身只改变视觉，不授予飞行权限。

`PonyFlightAnimations` 从当前 `fly` 动画的第一帧派生内部悬浮姿势。前腿整条保留原收腿幅度的 95%，小腿、蹄子的角度与位置补偿保持配套。普通悬浮只将整条前腿从腿根放低约 30°；冲刺时平滑抬回原冲刺高度。后腿保持普通 60%、冲刺 95% 的规则。躯干、头颈恢复中性基础姿态，头部视角跟随再独立叠加。模型、UV、贴图和 Blockbench 工程保持原样；资源包更新源动画时，派生姿势也随之更新。

源文件为 `src/main/resources/assets/magicaland/animations/mare_animation.json` 中的 `fly`。目前没有独立的悬浮动画资源，`internal.levitate` 由代码派生。修改 `fly` 也会影响有翼飞行；需要只调无翼姿态时，对应倍率在 `PonyFlightMotion`，派生与补偿分别在 `PonyFlightAnimations` 和 `PonyFlightPose`。左右前小腿骨骼名为 `LFrontCalf`、`RFrontCalf`。

进入悬浮用 5 游戏刻（约 0.25 秒）过渡，退出用 4 刻（约 0.20 秒）。身体前后倾斜最多 10°、侧倾最多 5°；腿根附加前后摆动最多 18°、侧摆最多 8°。这些是父子骨骼各自的附加角度，最终蹄部方向还包含原动画的姿势。移动和加速会带动四肢，停止后逐渐回稳。

上下加速度让前腿从根部产生最多 ±4° 的小幅惯性，小腿和蹄子维持蜷曲形状。后腿沿用最多 16 个百分点的瞬态调整，总收腿范围为原姿态的 44%–100%。匀速后回到基准，刹停与反向也按实际加速度平滑响应。

前腿使用同一套 95% 旋转与位置补偿；普通／冲刺切换只改变 `ForeLeg` 腿根，保留左右原有差异。降低和抬高都带动完整的父子链，不再单独反解蹄部朝向。关节接缝仍需结合实际资源在游戏中检查。

`PonyFlightMotion` 每游戏刻更新，渲染只做插值采样；远端玩家使用实际位置变化。传送、换世界、更换实体、断线时清理运动历史。`PonyFlightPose` 临时叠加到身体和四个腿根，绘制结束恢复骨骼及变更标记；背包、捏脸预览和缩略图不叠加这层惯性。

同步仍发送 `fly`、`elytra_fly`，接收端按该玩家的外观配置选择内部动画。表情分配沿用对应动作，公共 API 和服务端消息格式保持兼容。

## 包身光

`BodyFlightAura` 捕获正常绘制时的可见几何与贴图透明区域，先合成整只小马的剪影，再生成柔边。躯干内部只有很淡的染色，关节重叠部分不会逐块累加亮度。颜色取该角色已保存的魔法颜色；原有角和手持物光效继续使用原来的绘制流程。

普通画质在云层、天气之后叠加光效，仅写颜色并保留深度测试；后方云不会覆盖近处魔法光。Fabulous 在透明合成前写入独立实体目标的深度，交给原版按深度合成。隐身和观察者不生成包身光，第一人称手持物、界面预览也不生成该光效。

包身光内部染色系数为 0.045、外缘为 0.40，较初版更明显，仍保留身体细节。无翼独角兽悬浮时复用已有魔法音效，起飞、持续、落地均有平滑启停；持物与飞行共用音源，避免声音叠加。天马等有翼飞行和陆马悬浮不新增飞行魔法声。

合成时 RGB 保持加色，透明度独立使用 `ONE / ONE_MINUS_SRC_ALPHA`，避免淡光在原版 8 位透明目标中平方量化为零。光效结束后同时恢复底层绘制状态与 Minecraft 的混色缓存，防止干扰原版暗角。

额外绘制限制为距镜头 48 格以内、每帧最多 24 只和 65,536 个顶点；中间纹理最长边为 1,024 像素，跨帧复用。超过预算时保留正常角色，只省略额外光效。非原版多重采样目标暂跳过此效果，第三方光影兼容性需单独验证。

## 屏幕边缘光罩

无翼独角兽以第一人称本体视角悬浮时，屏幕最外圈会出现跟随魔法颜色的柔光，提示自身正被魔法托起。第三人称隐藏这圈屏幕光罩，角色身上的包身光保持原样。起飞渐亮，落地淡出，并带少量缓慢流动。光圈约占屏幕短边的 8%，中心区域保持透明。

光罩读取已应用的外观和解剖覆盖，不受捏脸草稿影响。有翼角色和无角角色不显示。打开界面、隐藏 HUD、进入外部相机或远控视角时隐藏；关闭小马模型替换也会停用。

这层效果使用普通界面网格，不读取世界画面，不创建额外帧缓冲，不改动包身光或飞行规则。代码为 `UnicornFlightRim` 与 `UnicornFlightRimMath`。

## 验收重点

- 有翼角色普通飞行、冲刺飞行与转弯仍保持原效果。
- 无翼角色起飞、横移、前后移动、上升下降、刹停与落地衔接自然。
- 前腿在普通／冲刺时都保持蜷曲；普通放低约 30°，冲刺抬回，切换连续。上下加速时有小幅根部惯性，匀速后回稳。
- 飞行中切换有翼／无翼预设，身体不残留拍翼时的压缩和头颈姿势。
- 无翼独角兽空手起飞也会亮角，包身光跟随魔法颜色；有翼天角兽使用拍翼。
- 第一人称本体视角的屏幕边缘柔光跟随魔法颜色，中央场景保持清楚；落地后消退，第三人称、界面与远控视角不残留。
- 正面、背面、侧面和斜角观察关节，确认四肢补偿和头眼追踪保持正常。
- 普通／Fabulous 画质下靠近墙壁、玻璃、水面，检查身体、背景和柔边遮挡；在多人同屏时检查帧率。
- 飞行期间打开背包或捏脸，关闭后确认世界角色姿态不受预览影响。

独立逻辑回归入口为 `tests/render/run-flight-tests.ps1`，需要已有开发依赖的 classpath 文件，可用 `-JavaBin` 指定 JDK。该入口包括飞行运动、派生动画以及屏幕边光的几何、渐变和界面层检查。`PonyFlightPoseTest` 另检查绘制后的骨骼恢复；`BodyFlightAuraShaderTest` 用隐藏的 OpenGL 场景检查实际着色器。独立测试不能替代游戏内的姿态、光效观感和兼容性验收。
