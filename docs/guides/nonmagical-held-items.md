# 嘴咬与蹄托持物试作

[文档目录](../README.md)

无角小马使用嘴与前蹄展示物品；有角角色继续使用魔法持物。首版已进入游戏测试，未修改模型、UV、贴图或原动画文件。

## 当前表现

- 工具、剑、三叉戟等用嘴咬住柄。主手优先使用嘴，另一件工具改用前蹄，避免两件物品占据同一嘴部位置。
- 其他物品由对应前蹄托住；盾牌附在前腿外侧，左右手设置仍然生效。
- 托物姿势取现有起飞动画的蜷腿角度和关节补偿，整体转到前方，让蹄底朝上。放下物品后用四个游戏刻恢复原步态。
- 嘴咬物品攻击时，头部最多轻摆约 6°、轻点约 3°，不改变玩家视角、判定或攻击距离。
- 食用、饮用时，拿着该物品的整条前腿从肩部抬起，并轻微起伏；食用约抬 24°，饮用约抬 28°。开始和结束都有过渡，小腿与蹄子的相对角度及关节补偿不变。动作跟随原版使用状态，支持主副手和左利手；不要求物品精确贴嘴。
- 第一人称隐藏人类手臂，物品位置与使用动作沿用原有实现，独角兽的魔法惯性保留。
- 托着物品的前蹄不播放落蹄声，其余腿继续按原步频播放。

## 维护与验收

分工在 `PonyHeldItems` 与 `PonyHeldItemPose`。物品挂在当帧头部／蹄子的实际变换上，跟随转头、动作和身体移动，不使用额外漂浮插值。骨骼修改只在本次渲染内有效，结束后恢复。

独立检查覆盖物品分类、主副手、原有子关节补偿、蹄底朝向、食用／饮用识别、整臂抬起方向、动作中断、不同渲染频率和骨骼状态恢复。第一人称隐藏手臂的注入需同时验证普通持物和地图。

食用动作加入后，160 份外观源码通过 Java 17 编译，780 项持物与原动画检查通过，并完成真实 Minecraft 渲染／输入目标类的无窗口注入检查。随后已在隔离快照中完成构建并启动测试游戏，用户同意推送当前版本。这不代表所有物品、姿态和多人组合均已完成验收。

仍需游戏内检查嘴柄位置、不同工具大小、盾牌方向、走跑时的托物轮廓、食用／饮用、左右手和多人显示。第三方异形物品可能需要单独的偏移预设；弓弩拉弦等第三人称动作后续再细化。
