# 款式缩略图维修（2026-09-08）

前发、后发、尾巴和眼型卡片暂用固定示例配色：白色素体、柔和紫灰鬃毛、默认蓝色虹膜，不显示玩家挑染。款式选择和左侧主预览的实时调色不变；草稿保存/应用与多人同步机制未改。

## 修复内容

- 缩略图缓存键只包含部件、款式编号和图像尺寸，不读取玩家的颜色、锁定、挑染或预设名。连续拖色不再使缩略图缓存失效。
- 图像宽高用同一个缩放系数限制到 192 像素，再等比居中绘制；宽卡片不再把小马横向拉宽。
- 创建、绘制、淘汰与清空离屏图均恢复调用方的读/写 framebuffer、viewport、scissor、纹理绑定、混合、深度、颜色写入、shader 和顶点缓冲状态。不把 framebuffer 0 或固定主 framebuffer 当作调用方。
- 不再改写全局 shader 光照方向；卡片沿用 GUI 的标准方向光，主预览自己的光照设置保持原样。

## 后续

实时缩略图调色已列入项目 TODO。未来恢复前应先实现旧图回退、合并连续调色请求及稳定帧预算，避免每次颜色变化都新建整池离屏图。初次打开或改窗口尺寸时仍按每帧最多两张渐进生成；这不是颜色编辑触发的重建。

本轮采用独立 Java 17 类型检查、真实几何检查、比例计算检查及隐藏 OpenGL 上下文回归，不构建或启动 Minecraft。完整游戏交互仍需后续验收。

OpenGL 验证范围是原版 GUI/实体采用的混合模式及本模组的嵌套离屏目标。第三方若使用 RGB/alpha 不同的独立混合方程，退出时实际 GL 值可以恢复，但未额外改写 Minecraft 私有 shader 混合缓存以保证其所有后续组合；这类扩展不在本轮已验收范围内。
