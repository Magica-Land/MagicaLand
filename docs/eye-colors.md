# 眼部独立调色

面部页面增加虹膜主色。左侧小三角展开浅色区域：默认随主色计算，解除锁定后可以独立调色；解除锁定时保持当前显示色。保留原贴图渐变、细微色差和白色反光点，极暗虹膜保留很小的明度底限，避免层次完全消失。

“高级眼部颜色”默认收起，包含睫毛、眼白、瞳孔，均可独立编辑，并可单独恢复高级眼色默认值。调整睫毛也会影响闭眼线条。眼白保留原有浅阴影，白色反光点不参与调色。

## 实现

- `ModelConfig` 新增 `irisColor`、`irisLightColor`、`irisLightColorLocked`、`eyelashColor`、`scleraColor`、`pupilColor`。旧配置缺少字段时保留原蓝色虹膜、黑睫毛/瞳孔、白眼白；非法颜色经 sanitize 回退。沿用预设 Gson 保存及现有多人模型配置同步，不增加协议或改动画。
- `IrisPalette` 用原图明暗相对关系重映射两个虹膜区域，默认值逐像素还原。`EyePalette` 仅处理眼部图集中的已知区域，保留透明度。
- `EyeMaterials` 根据表情库识别眼部骨骼，包含三种眼型及共有表情。生气表情的瞳孔与睫毛同骨骼、同黑色图区，因此渲染时按 cube 的 UV 拓扑区分箱式瞳孔与窄条睫毛，分别使用对应颜色。不能只按骨骼染整片黑色。
- `EyeTintTextures` 缓存派生贴图，最多 64 项 / 32 MiB，默认颜色直接使用原图；重载、断线和退出释放资源。渲染中不销毁其他玩家尚未提交的贴图，容量不足或资源异常时安全回退原色。
- 本次没有改原始 base.png、MareMane、Blockbench 文件、UV、Rig 或动画。将来的眼型沿用现有逻辑图集/UV 拓扑即可复用；如果换图集位置或瞳孔展开方式，需要更新材质适配及测试，不需要逐动作修改颜色动画。

## 检查与验收

- `tests/eyes/IrisPaletteTest.java`：原色逐像素一致、透明度、渐变排序、黑白及随机颜色、自动/手动浅色、旧配置、保存与同步序列化。参数为 `base.png` 路径。
- `tests/eyes/EyeMaterialsTest.java`：实际 GeckoLib 模型中 15 个眼部骨骼、8 个瞳孔（含生气表情）均正确区分；参数为 `mare_geo.json` 路径。
