# 魔法手持物音效

音效只为现有独角兽手持魔法配声，不增加施法、攻击或传送能力，不从渲染帧或捏脸预览里触发声音。

## 素材与处理

用户于 2026-09-08 提供下载文件夹「小马宝莉魔法音效」。文件夹中共 18 份 WAV，没有来源链接、作者或许可文件。本次仅使用：

| 原文件 | 运行资源 | 用途 |
| --- | --- | --- |
| Magic spell cast 1.wav | magic/cast_1.ogg | 随机施法起音之一 |
| Magic spell cast 2.wav | magic/cast_2.ogg | 随机施法起音之一 |
| Magic spell aura.wav | magic/aura.ogg | 悬浮期间的轻循环 |
| Magic spell end.wav | magic/end.ogg | 正常结束时的短尾音 |

原始下载文件保持不变。运行文件转为 48 kHz 单声道 Ogg Vorbis，避免立体声素材失去空间定位。左右声道以各 50% 混合，不用可能增加峰值的默认立体声下混。只衰减、不抬高增益，预留编码余量；解码后峰值均低于 -6 dBFS。四份资源共约 72 KiB，不导入其余攻击、防御或传送素材。

起音、结束声仅处理极短的首尾淡化，保留原有声形。持续声取原文件 0.15–3.05 秒主体，去掉末端较强的起伏，以 180 ms 首尾交叉淡化制成 2.72 秒循环；运行时另做音量包络。音频幅度、时长、输入输出 SHA256 记录见 `magic-sound-assets.json`。

用户已确认这些网上公开素材允许用于同人创作，本次按用户提供的使用许可说明接入。下载文件夹未附来源链接和作者记录，后续补齐出处与署名，已列入项目 TODO；素材不自动适用项目代码的开源许可。

## 触发与音量

声音由客户端世界 tick 中的已应用外观、角开关和持物状态控制，模型草稿不参与。主副手合成一份状态，非空物品之间换槽不重复起音；空手做短去抖，避免一帧网络或换槽空隙产生连续响铃。

本地玩家正常拿起或放下物品才触发起音和结束声。进入游戏、邻近玩家进入范围、外观同步、开关或音量恢复只静默恢复持续声，不补播施法起音。远端只播放轻持续声，避免多人入场时集中响铃。

空手持续 3 tick 才确认结束，起止短音至少间隔 8 tick。同一玩家的新起音或结束声会先停止旧短音，避免快速操作将多个较长起音叠加。

使用 `SoundCategory.PLAYERS`，受游戏的主音量和“玩家”音量控制，不修改用户全局设置。起音 / 持续声 / 结束声播放系数分别为 0.12 / 0.035 / 0.09，叠加素材预先降幅；持续声淡入约 0.4 秒、正常放下后淡出约 0.5 秒。

资源声明 8 格衰减距离；本功能的移动音源使用客户端手动距离增益，2 格内保持基准，2–8 格平滑衰减至零，不再叠加引擎的第二次距离衰减。音源位置仍跟随玩家，保留左右方位。运行时限制近处少量声源，同时循环上限为 4 名玩家，包含自己及淡出中的声音。隐身、死亡、旁观、断线、世界切换及关闭模型替换等情况清理声音；不为隐身角色暴露位置。本地第一人称关闭手持魔法光效后也停止配声。

循环资源预加载但不流式读取，使用引擎零延迟循环，不靠定时重新播放整段录音。客户端无需额外声音网络包或服务器注册；客户端各自根据已有玩家和外观同步状态计算。

## 验证

转换后重新解码检查四份单声道 Vorbis 文件，核对时长、有限样本、峰值和持续声接缝，原 WAV 的 SHA256 保持不变。客户端独立类型检查和声音状态回归不运行 Gradle，不打开音频设备播放声音。

另用 Minecraft 1.20.1 真实 `OggAudioStream` / `RepeatingAudioStream` 做兼容检查：整段读取与分块读取逐字节一致，PCM 样本数与容器时长一致；持续声连续三轮解码完全重复，无空边界块。元数据清单里的 `processed.seconds` 是 FFmpeg 回读值，短文件 cast_2/end 的 FFmpeg 回读比容器少 128 样本，Minecraft 解码没有该截短，分别为 0.365708 / 0.809792 秒。

本轮不启动游戏，尚未进行耳听或多人实机验收。下一次验收重点是低音量下的可听度、长时间持物是否疲劳、快速换槽/双手/开关/断线没有重叠或残留。
