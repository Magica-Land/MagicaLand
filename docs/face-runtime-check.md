# 表情系统游戏验收（2026-09-08）

本轮限定范围的表情功能验收通过，未发现新的叠眼、残影或切换错误。这不是完整发布验收。

## 已验证

- 经用户授权，在隔离的 Minecraft 1.20.1 / Fabric / GeckoLib 4.8.3 开发环境编译、启动并正常退出。
- 标题与捏马预览可切换 01／02／03 眼型；普通、笑眼、生气、闭眼和挤眼可经表情 ID 调用。
- 奔跑、跳跃、下落、潜行的正式动作选择与表情分配正常；受伤状态选择挤眼，睡眠状态选择闭眼，结束后恢复普通眼。
- 普通眨眼及原眼仁缩放保留；动作指定笑眼／闭眼／挤眼时，普通眨眼不会替换其眼型。
- 03 使用自身笑眼几何；挥手、芭蕾的面部片段可独立调用。

## 证据与测试边界

结构迁移检查通过 379 项，独立 Java 回归测试通过 5029 项断言。游戏验收校验了 74 个源码、资源与构建配置文件的 SHA-256；验收前后正式文件及测试副本保持一致。运行时验证通过 905 项断言，首轮采集 297 张游戏帧，最终睡眠多视角补测采集 54 张。

动作检查使用原版输入标记和隔离世界内的位置设置，并记录正式控制器选择的动作。受伤通过客户端 `hurtTime` 测试状态触发，不代表战斗或伤害系统验收。

睡眠补测设置原版睡眠位置与睡眠姿态，并确认 `isSleeping=true`、主动作 `sleep` 及闭眼通道。为拍摄眼睛，测试辅助工具临时抑制睡眠界面与黑屏淡入；正式代码未修改。首轮未真正进入睡眠的三个样本已排除，不能计作通过。未覆盖右键床铺、床铺朝向对齐或整夜睡眠交互。

表情库检查在内存中临时将 idle 映射到不同表情 ID，结束后恢复。挥手／芭蕾仅验证面部片段在 idle 身体上的调用和眼型适配，尚未验收完整身体编舞与面部同步。双客户端多人同步、完整光照矩阵也未覆盖。
