# 文档维护

首页介绍功能、安装和使用。文档索引按玩家说明、开发资料、历史报告与规划分类；Gameplay 的正文维护在玩法仓库，外观仓库保留入口。

项目介绍按系统分类：外观包介绍角色自定义与显示，玩法包介绍三族能力、成就系统等内容。具体能力和趣味事件放在所属系统的功能文档中；进度说明区分已实现内容与规划，历史报告保留当时的测试对象。

## 文件位置

- 新的玩家指南放在 `docs/guides/`。
- 开发方法和公共接口说明放在 `docs/development/`。
- 独立测试报告使用 `docs/reports/YYYY-MM-DD-主题.md`。
- 规划明确标注状态，避免与现有功能说明混淆。
- 旧文档继续保留原路径。以后移动文件时，一起更新内部引用；对外分享过的路径保留跳转说明。

## 报告内容

记录日期、对应提交、测试环境、复现或执行方法、结果、未测项和后续问题。跨仓测试同时记录两仓提交。

独立编译、逻辑测试、构建、开发客户端启动、人工验收与多人实测分别填写。历史报告保留当时观察；修复后追加新记录和链接。

## 附件

仓库保存精简结论、精选截图和可复用测试。截图说明它来自游戏、离线预览还是示意图。

原始日志、批量截图、视频和实验备份单独存放。构建缓存、依赖副本、临时启动参数、测试世界和个人配置留在本地。玩家下载的正式 JAR 使用版本发布入口。

公开前检查文件中的个人信息和访问凭据。原始证据中的本地路径可帮助作者查证，正式使用说明采用仓库相对路径或清楚标注的示例路径。
