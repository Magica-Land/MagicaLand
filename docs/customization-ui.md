# 捏脸界面新版

捏脸页使用全宽布局，不再叠加原来的宽侧边导航。设置、外观和关于仍可从顶部进入。

- 顶部分类：身体、鬃毛、面部、角与翅、魔法、预设。
- 左侧：角色预览、预设切换及重命名、自动聚焦开关，框内底部切换白天／正午／夜晚。
- 右侧：当前分类的独立滚动细项，各分类分别记住滚动位置。
- 鬃毛拆成前发／后发／尾巴子栏，每栏只显示自己的缩略图池和颜色。眼型同样使用缩略图池。编号以实际资源为准，不填补暂缓的 07 后发或 08 尾巴。
- 拖动预览旋转，上下拖动已修正；右键或重置按钮恢复当前聚焦角度，关闭自动聚焦后立即恢复正常全身视角。手动模式且空间足够时保留视角方块。
- 魔法分类可切换小马／悬浮物品光效预览，保留原有待机、眨眼、耳朵和尾巴动画。

主光来自镜头左上后方 45 度，另有正面补光，避免仅侧面亮。昼／午／夜是局部色调模拟，供对比配色，不是世界天气的精确复现。不会修改世界时间、保存的颜色或其他玩家。魔法光晕保持发光。

预览上方点击名称切换下一个预设；“预设”分类提供完整列表、新建、复制和删除。复制会深拷贝所有颜色、锁定和分色数组，自动生成不冲突的副本名称并选中。铅笔开启重命名，确认／Enter 接受名称草稿，取消／Esc 放弃名称输入。命名期间禁用右侧编辑和保存应用；窗口尺寸变化保留输入。名称继续遵守既有文件名和长度限制，禁止覆盖其他预设。

所有原有调色、自动高光／阴影、锁定、六区挑染、虹膜渐变和高级眼色均保留。色板浮层不被右侧滚动裁切；Esc 优先关色板，点击外部也仅关闭色板，不穿透触发后面的款式。

## 缩略图与镜头

缩略图从当前资源包的真实模型独立烘焙，使用固定参考配色、无其他鬃毛的素体试穿目标部件。前发、后发、尾巴和眼型缩略图都不再跟随草稿调色；左侧角色主预览仍实时显示全部颜色、锁定和挑染。恢复缩略图实时调色列为后续待办，不影响当前编辑功能。

离屏图带深度，生成和显示保持相同比例；大窗口不把小图片无限横向拉宽。只处理可见卡片，离开或资源重载时释放。离屏创建、缓存淘汰与清空必须恢复调用前的渲染目标和受影响状态，不能让缩略图清理把后续页面绘制切到 framebuffer 0。不会修改玩家配置或世界共用的动画骨骼。

选择前发或眼型聚焦头部，后发转到头后侧，尾巴转到臀部斜后方。根据真实部件和必要素体的包围盒拟合距离，平移、旋转与缩放按经过时间平滑过渡，不跟随鼠标悬停跳转。静止视角保留边距容纳待机运动；过渡途中允许短暂经过原来的裁切位置，完成后完整显示目标部件。

款式卡片使用方向键浏览，Enter／空格确认选择，当前选中与键盘焦点分别标示；右栏按实际条目高度滚动和命中，不再假定所有控件都是一行高。

## 保存保护

捏脸外观及预设操作在完整的内存草稿会话里编辑。`getActiveModel()` 给 GUI 草稿，世界渲染、手持物和网络发送只用 `getAppliedModel()`。切到“设置／关于”、更换款式、调色、切换／复制／新建／更名／删除预设都不会提交草稿。全局设置开关仍沿用原有保存方式，不属于外观事务。

只有“保存并应用”才提交本次所有预设操作，更新当前外观并广播一次。关闭有未保存内容时询问是否丢弃；丢弃、异常离开或断线恢复上次已应用外观，不写预设、不发模型更新。保存成功退出界面后触发变身光尘（28 个光点和 4 个微星，约 0.8 秒，无声音），从随身体朝向旋转的外轮廓散开，尺寸和亮度较首版提高；仅保存名称或没有外观变化不重复炸开。历史模型同步和服务器握手不播放变身效果。

服务器保留每名玩家最近一份合法外观，在原 100 ms 限流到期后应用，防止连续保存遇网络抖动丢失最终结果；关闭广播、断线和服务器停止清理等待项。无需新协议或确认包。光尘受粒子数量设置和短冷却限制，隐身、遮挡等情况不额外泄露角色位置；普通模式不写世界深度，Fabulous 模式仅写独立粒子目标的深度供透明层合成。

JSON 使用 UTF-8。提交前核对外部文件变化，预写临时文件并保留回滚备份；失败不应用或广播，草稿仍在。损坏 JSON 不加入编辑列表，也不会被覆盖或误删。若故障导致回滚也无法完成，保留 `.appearance-edit-*` 恢复文件并在日志给出路径。此流程防止常规写入失败，不宣称多文件修改在断电时具有数据库级原子性。

## 回归检查

- Java 17 全部变更联合类型检查，包含手持物光晕、编辑草稿和粒子网络，不运行 Gradle。
- `CustomizationLayoutTest`：320×240 至 1920×1080 的布局、控件和旋转区域边界，共 328233 次检查。
- `PreviewCameraTest`：715409 项完整入镜、窗口尺寸、平滑过渡、最短角度和立即复位检查。
- `StyleGridLayoutTest`：自适应列数、命中间隙、可见卡片、键盘和资源编号检查。
- `PreviewGeometryBoundsTest`：真实模型、私有状态、配件范围及固定缩略图配色检查。
- 缩略图宽高比和离屏渲染状态回归覆盖缓存淘汰、清空及嵌套 framebuffer。
- `TransformationBurstMathTest`：41748 项数量、亮度、寿命、轮廓分布和身体朝向检查。
- 预设兼容与草稿事务检查必须使用隔离的 Fabric／配置／网络 stub 和临时目录，不能对玩家真实配置目录运行。
- 中英文文案完整性检查。

本轮维修未重新构建或操作游戏。下次测试重点：宽／窄屏款式池等比显示、连续调色及离开页面不闪烁、缩略图固定颜色而主预览继续实时变色、保存光尘可见性、头部视角跟随与原眼仁追踪，以及第一／第三人称悬浮惯性和冲刺拖尾。既有草稿保存／丢弃和多人同步保护仍需回归。
