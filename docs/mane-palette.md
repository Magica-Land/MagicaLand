# 鬃毛与尾巴调色

2026-09-07：将身体已有的自动色阶调色接入前发、后发和尾巴。不修改原鬃毛贴图、UV、分辨率或动画。

## 玩家操作

- 默认使用色阶调色。前发为主配色，后发和尾巴各有一个联动锁；锁定时整套主色、阴影和高光跟随前发。
- 解锁后发或尾巴时先复制当前可见配色和阴影/高光锁状态，不发生跳色；随后可以各自调整主色，并分别解锁阴影、高光手调。
- 阴影和高光默认自动计算。解锁保留当前颜色，主色再变时手选色保持不变；重新锁定恢复自动计算。
- 重新锁定后发/尾巴立即跟随前发。再次解锁使用此时可见的前发配色，而不是恢复上一次独立配色。
- “高光/阴影恢复自动”只重置三处阴影与高光的锁，不合并已经独立的后发和尾巴主色。
- 可切换为传统乘色作为旧效果对照/回退；此模式仍保留部位联动，但不使用阴影、高光色阶。切回色阶调色保留手选值。

## 实现与兼容

- `ManePalette` 统一处理骨骼部位映射、联动、解锁快照和配色读取。`BodyColorRamp` 提供与身体相同的自动色调及灰度查找表；不额外乘一次主色。
- `ManeTintTextures` 读取资源包中的 `textures/entity/mane.png`，按实际主色/阴影/高光三元组缓存整张调色纹理。三处同色时共享同一张缓存；异色时分别使用对应纹理。
- 缓存上限 128 项、64 MiB（按 CPU/GPU 双份像素估算），空闲回收；资源重载、断开连接和退出时释放。失败或容量不足时回退为使用同一联动主色的传统乘色。
- `ModelConfig` 保存 `maneShadingMode`、两处联动锁、六个阴影/高光色及各自的锁。`maneColorLinkVersion` 标记一次性的联动迁移，不是发型编号版本。
- 无迁移版本的旧配置：已有不同主色的部位保留为独立状态；相同 RGB（兼容六位及八位十六进制）设为联动。规范化后版本为 1，后续加载/保存不会重新猜测联动状态。
- 本地保存、界面预览和远端模型使用同一配置；现有整对象 JSON 联机通道无需改协议。保存时联动部位的主色同步写入旧颜色字段；旧客户端可读取主色，但不认识新色阶与锁状态，外观仍可能不同，请使用相同新版客户端验收。
- 身体色阶算法与身体界面不变。Blockbench 只保存源灰度贴图，不烘焙玩家运行时配色；`BaseTextureBackup` 仍仅供工程预览。

## 验收清单

- 新配置：改变前发主色，后发和尾巴的主色、自动阴影/高光一起变化。
- 解锁前发阴影或高光并手调，仍锁定的后发、尾巴同步显示；两种色阶的锁互不影响。
- 分别解锁后发和尾巴，确认解锁瞬间不跳色，然后设置三个不同主色及独立的手动色阶。
- 保存、切换模型、重新加载及同版本联机后，三套配色和所有锁状态一致。
- 重新联动、再次解锁、重置自动、切换传统模式和资源重载均正常；身体配色不受影响。
- 验证 AJ 前发仍为微收拢尖端版本、后发 `08` 仍是原丸子头；列表无后发 `07` 和尾巴 `08`。
