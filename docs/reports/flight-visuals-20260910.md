# 飞行姿态独立检查 — 2026-09-10

本页保留初次实现阶段的检查记录。后续姿态与设置调整、最新构建及用户验收见[汇总记录](unified-magic-20260910.md)。

本轮实现有翼拍翼、无翼直立悬浮及无翼独角兽包身光。改动位于外观包客户端；玩法仓库、同步协议、公共 API、作者模型与贴图保持原样。README 草稿保留现状。

## 已通过

| 检查 | 覆盖内容 |
| --- | --- |
| 全部 141 个 Java 源文件独立类型检查 | Java 17 目标、当前真实开发依赖；不使用旧模组类代替新代码 |
| 飞行状态与派生动画 | 起落过渡、速度／加速度惯性、横移朝向、重复渲染与传送重置；12 条原肢体旋转和关节补偿、有翼／无翼切换 |
| 骨骼隔离、原有头部和手持物回归 | 每次绘制结束精确恢复姿态与变更标记，界面和重绘排除；原头眼、物品收放和惯性测试通过 |
| 13 套界面逻辑回归 | 布局、取景、预设、草稿、缩略图与预览隔离；另 1 套界面 OpenGL 测试仅完成编译 |
| 公共 API 与分包边界 | 95 项 API 检查、仅依赖 API 的使用方编译、498 项仓库边界检查 |
| 实际 OpenGL 着色器检查 | 451 项：三个程序编译、透明贴图、关节重叠、流动与渐入、前景墙遮挡、主深度保持、原版 Fabulous 合成、4K 场景深度降采样及斜面淡填充 |

显卡检查使用隐藏的独立场景，在 NVIDIA GeForce RTX 4070 SUPER 上执行，未启动 Minecraft。着色器测试使用生产着色器和原版 Fabulous 合成程序；它覆盖渲染算法，不代表整套游戏集成已经验收。

复核中修正了深度缓冲清空顺序、背包渲染与世界姿态的隔离，以及高分辨率深度降采样导致的斜面自遮挡误差。

## 尚需游戏验收

起落和四肢摆动的观感、各种配件下的关节轮廓、多人同步实机表现、玻璃／水面场景、游戏帧率，以及第三方光影兼容性。具体操作见 [飞行姿态说明](../flight-visuals.md#验收重点)。

本报告所记的初次独立检查阶段未执行 Gradle 构建或启动游戏。随后用户追加角光纹路调整并要求启动验收，已构建包含飞行姿态的独立测试包，见 [角光调整与测试记录](horn-pattern-20260910.md)。尚未提交或推送。
