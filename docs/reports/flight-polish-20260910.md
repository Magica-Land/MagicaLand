# 悬浮、魔法光与配声调整 — 2026-09-10

本页记录中途调整阶段；前腿角度和能力视角入口已在后续迭代中调整，当前方案与验收见[汇总记录](unified-magic-20260910.md)。

## 改动

- 无翼普通悬浮使用作者起飞姿态 60% 的收腿幅度，冲刺平滑加到 95%。上升加速时舒展、下降加速时向上收腿，调整最多 16 个百分点，整体限定在 44%–100%；匀速后回到基准。原关节补偿与旋转同步插值，有翼动画保持原样。
- 角光保留宽而不规则的流动纹路，增大明暗反差，12 秒周期及角周接缝连续。包身光内部与外缘强度分别调整为 0.045、0.40。
- 普通画质延至云层、天气之后叠加魔法光，保留前方云与墙的深度遮挡；Fabulous 继续在原版透明合成前提交。
- 无翼独角兽悬浮复用已有施法起音、轻持续声和结束声，与持物共用音源；音频文件及基准音量不变。
- 玩法仓库独立修改远控默认视角为背面第三人称，F5 可继续切换，结束后恢复原视角。

## 验证

当前外观包 141 个 Java 源文件独立类型检查通过。飞行状态、派生姿态、骨骼恢复、原头部跟随、手持惯性、物品入场与声音状态回归通过。角光、点亮进度、物品光、拖尾及深度顺序的五套独立显卡测试通过。云层顺序测试验证实际编译后的事件回调，并结合生产着色器与原版透明合成检查前后遮挡。

起飞黑屏的真实 Minecraft 暗角回归继续通过。追加检查还发现 Fabulous 的 8 位透明目标会将淡光的透明度平方量化成零，现已将 RGB 加色与透明度混合分开。真实 8 位目标、原版 `PostEffectPass` 与透明合成验证中，淡光不再被丢弃；实际管线共 197 项断言通过。云层及透明度负对照共 33 项检查通过，包身光像素回归 452 项通过。

这些检查不代替游戏内的动作、音量及第三方光影验收。本轮追加改动未重新构建、重启当前游戏或推送；正在运行的游戏是此前的黑屏修复测试包。
