# 角部光纹调整与测试 — 2026-09-10

本页记录最初仅调整角光的阶段。后续统一光效、最终测试构建及用户验收见[汇总记录](unified-magic-20260910.md)。

角上的规则滚动亮带改为宽而不等距的柔和光纹，降低明暗反差，并保留缓慢游动。角光颜色、包络大小、柔边、点亮／熄灭进度和深度顺序保持原样。星星、物品和拖尾的生产着色器分支逐段比对未变。

五套独立 OpenGL 回归通过：

- 角光：3,012 项，包含 12 秒循环、圆周 UV 接缝、逐帧平滑及横向纹路差异。
- 点亮与熄灭：133,783 项，包含根部到尖端推进、倒放、多人独立进度及深度。
- 物品光效：15 项。
- 光晕绘制顺序：16 项。
- 拖尾：81 项。旧测试前半段误用角光分支，本次修正为生产实际使用的拖尾分支；生产拖尾未改。

测试期间，采样点在 60 fps 下的最大逐帧透明度变化约为 0.00392；这仅用于检查是否突变，实际观感仍需游戏验收。
