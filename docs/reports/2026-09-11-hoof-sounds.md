# 马蹄声接入检查

日期：2026-09-11。对象：外观 0.3.5 开发工作区，基于 `5724bdf` 及其后尚未提交的飞行 API 修改。功能归属外观包，不依赖 Gameplay。

## 本轮范围

- 按现有四蹄动作记录走、跑、倒走、蹲行的接触节拍；同一时刻的落蹄合并，蹲行同步减速并降低音量。
- 本地精确拦截玩家脚步；联机增加服务端能力握手，使用原版实体声音消息区分玩家。没有同步能力或没有对方外观时保留原声。
- 保留涉水和原版 `STEP` 事件；未跟踪实体时保留坐标声音。
- 修正检查中发现的传送误播落地声、短暂离地误播重落地声。动画、模型及贴图文件均未修改。
