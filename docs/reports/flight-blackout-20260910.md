# 起飞黑屏排查与修复 — 2026-09-10

本页保留黑屏定位与修复记录。后续渲染回归及最新构建、用户验收见[汇总记录](unified-magic-20260910.md)。

## 现象与定位

测试时起飞后世界画面变黑，第一、第三人称均受影响；物品栏、准星和菜单仍能绘制，方块交互正常。落地后黑屏持续。

运行中读取的世界绘制结果仍有夜空和木块，最终窗口却只有黑底与界面。原版暗角位于这两个阶段之间。使用实际 Minecraft 着色器、帧缓冲类和原版暗角贴图复现后，确认身体光效留下了错误的混色缓存。

`BodyFlightAura` 的遮罩、柔化和合成依次切换不混色与加色。原实现恢复了底层 OpenGL 参数，却未恢复 `GlBlendState.activeBlendState`。之后原版暗角绑定着色器时将乘色覆盖为普通透明度混合，暗角贴图的不透明黑色区域覆盖了世界；界面在其后绘制，因此不受影响。残留缓存解释了落地后仍然黑屏。

## 修复

在已有 access widener 中开放该缓存字段，随其他绘制状态保存原引用，并在 `finally` 路径恢复。保留飞行姿态、身体光效和角光纹路；玩法包、同步协议与资源贴图不变。

原始着色器测试覆盖了遮罩与合成算法，没有串联原版暗角。新增实际 Minecraft 渲染链路回归，覆盖这一交接环节与后续帧。

新增回归已通过 180 项断言、9 个场景，包括首次分配、重复帧、关闭光效、分辨率变化、Fabulous 目标切换及混色缓存精确恢复。使用实际 Minecraft 渲染类和原版暗角贴图，验证世界颜色、最终呈现和后续 HUD 均正常。入口为 `tests/render/body-aura-integration/run-tests.ps1`；Fabulous 场景在此检查独立目标及状态，完整透明合成另由着色器回归覆盖。

## 测试环境说明

临时读取运行中帧缓冲未修改存档。后续方法取样与 Fabric 类加载隔离发生冲突，导致当次测试客户端退出；这是诊断程序的问题，与起飞黑屏的根因不同。该诊断程序未放入模组或新的测试启动配置。

重新构建使用隔离目录，启动前备份原测试存档与设置。仍需用户实机确认起飞、落地和切换视角后画面正常。
