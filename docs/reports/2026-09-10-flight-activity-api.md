# 飞行活动 API 1.5

Appearance 0.3.5 新增 `AppearanceOverrides.registerFlightActivity` 与 `flightActive`。扩展可在不设置原版飞行权限的情况下，使用现有飞行姿态、包身光、飞行音效与第一人称边缘光罩。角部施法继续使用独立的魔法活动注册。

主动作与待机判断已识别扩展飞行，避免悬浮时同时进入下落或待机动画。现有角色资源、UV、贴图、动画文件和外观同步协议保持原样。

已通过：全部外观源码的 Java 17 目标检查、API 行为与独立消费者编译、仓库边界、现有飞行姿态／惯性和第一人称光罩回归。测试脚本同时补上编译器异常检测，避免依赖访问失败时仍继续运行测试。

本轮没有进行 Gradle 构建、游戏启动或实机验收。Gameplay 悬浮的实际网络与操控表现仍需在新版游戏测试中确认。接口用法见[外观 API](../appearance-api.md#独立飞行表现)。
