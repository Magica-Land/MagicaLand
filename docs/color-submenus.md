# 颜色二级菜单

2026-09-08：按作者要求将已有高光、阴影控制改成颜色行下的可折叠子项，不增加新的调色字段，不修改模型、贴图、动画或色阶算法。

## 操作与范围

- 身体公共色阶、前发、独立后发、独立尾巴的颜色行左侧提供小三角；点击展开/收起。阴影、高光子项缩进 12 像素，锁仍控制自动/手动色阶。色块及其他颜色区域仍打开原有取色器。
- 进入页面时默认收起；同页切换锁、调色模式、恢复自动时保留展开状态。返回其他页再进入时重新收起，展开状态不写入玩家配置。
- 后发/尾巴联动时跟随前发的整组配色，不显示独立子项；解锁后可展开各自色阶。重新锁定隐藏子项，不改变原有联动语义。
- 身体仍只有原有的一组公共手动色阶；异色肢体继续使用原有自动计算，不为每条肢体新增独立手动色阶。传统乘色模式不显示色阶子项。
- 身体“全部恢复自动”收进身体子菜单；鬃毛“高光/阴影恢复自动”仍是页级操作，作用于三处色阶，不重新合并独立主色。
- 同页刷新在下一帧执行，避免在点击分发中途替换列表。恢复当前滚动位置和焦点行；列表缩短时按有效滚动范围限制位置，切页仍重置。
- 可聚焦颜色行后按右方向键展开、左方向键收起，也支持 Enter/空格切换；新增中英文说明和朗读提示。过长颜色标签限制在锁图标/色块之前。
