# 魔法手持物惯性与短拖尾

本次仅改变视觉位置，不创建物品实体，不改变攻击、射击或交互判定，不增加网络协议。

## 接入

- `Client` 初始化调用 `GlowingItem.initLevitation()`，注册世界帧与断线清理。
- 第一人称删除旧 `floatTime / magicalOffsetY / lastUpdateNanos`；第三人称删除独立正弦位移。静态摆位、左右手、原版装备/攻击/使用动作、三叉戟特例保持。
- `LevitationMotion` 对移动目标解析积分。以游戏 tick 和插值时间推进；暂停不推进，同一世界帧重复绘制不推进状态或重复记录尾迹。
- 状态按玩家 UUID、主/副手和视角分开；换世界、换视角、物品/NBT改变、不可见后重现、时间跳变和传送重置。最多 512 个状态、每条尾迹 8 个历史点。
- ItemStack 引用改变时立即比较，原对象 NBT 仅每 0.25 游戏秒检查；内容未变不复制 NBT，不在每帧序列化整份物品。

## 视觉参数

| 参数 | 第三人称 | 第一人称 |
| --- | --- | --- |
| 水平最大位移 | 0.20 格 | 0.085 格 |
| 垂直最大位移 | 0.14 格 | 0.065 格 |
| 最大角度滞后 | 8° | 3° |
| 尾迹寿命 | 0.18 秒 | 0.10 秒 |
| 最大尾迹长度 | 0.42 格 | 0.20 格 |

使用物品时幅度收紧到 22%，加快回正且不生成尾迹。睡眠、乘骑、不可见/死亡、非魔法路径不产生新的惯性或拖尾。地图和望远镜等原版特殊第一人称路径不改动。普通静止不再持续上下正弦漂浮，现有柔光流动与稀疏星星保留。

只有冲刺且实际水平移动超过 0.6 格/秒时生成细短光带。历史点保存世界坐标；尾端在长度上限处插值裁切，高速运动不会因为一段过长而整段消失。尾迹头在 `ItemAuraGeometry` 捕获完物品显示变换后取真实几何中心，避免不同工具/方块的偏心模型错位。

光带使用当前 `horn_aura` shader 的柔边流动分支，不添加完整物品残影。沿已有 `HornAuraPass` 延后绘制：世界普通模式只写颜色，Fabulous 写独立实体目标的排序深度；第一人称在两只手的原物品完成后绘制，不混用世界投影。捏脸预览不参与运动状态。

## 验证与边界

`work/levitation-rework-20260908/check.mjs` 使用缓存依赖局部 `javac --release 17`，运行运动/帧率/生命周期/高速尾迹、偏心几何/坐标基底、原有物品轮廓和隐藏 GPU shader/遮挡测试；不运行 Gradle，不启动 Minecraft。

尚未进入游戏做美术观感验收。当前参数是保守初值；多人视觉由各客户端用已同步的玩家移动自行重建，允许非常轻微的时间差。
