# 魔法手持物惯性与移动拖尾

本次仅改变视觉位置，不创建物品实体，不改变攻击、射击或交互判定，不增加网络协议。

## 接入

- `Client` 初始化调用 `GlowingItem.initLevitation()`，注册世界帧与断线清理。
- 第一人称删除旧 `floatTime / magicalOffsetY / lastUpdateNanos`；第三人称删除独立正弦位移。静态摆位、左右手、原版装备/攻击/使用动作、三叉戟特例保持。
- `LevitationMotion` 对移动目标解析积分。以游戏 tick 和插值时间推进；暂停不推进，同一世界帧重复绘制不推进状态或重复记录尾迹。
- 状态按玩家 UUID、主/副手和视角分开；换世界、换视角、物品/NBT改变、不可见后重现、时间跳变和传送重置。最多 512 个状态、每条尾迹最多 24 个轨迹点（含当前端点），历史容量与增长后的寿命同步扩大。
- ItemStack 引用改变时立即比较，原对象 NBT 仅每 0.25 游戏秒检查；内容未变不复制 NBT，不在每帧序列化整份物品。

## 视觉参数

| 参数 | 第三人称 | 第一人称 |
| --- | --- | --- |
| 水平最大位移 | 0.60 格 | 0.20 格 |
| 垂直最大位移 | 0.36 格 | 0.15 格 |
| 最大角度滞后 | 18° | 8° |
| 普通移动 / 冲刺尾迹寿命 | 0.40 / 0.80 秒 | 0.22 / 0.44 秒 |
| 普通移动 / 冲刺最大尾迹长度 | 1.0125 / 2.70 格 | 0.4125 / 1.10 格 |
| 普通移动 / 冲刺尾迹头部名义全宽 | 0.11 / 0.165 格 | 0.044 / 0.066 格 |

2026-09-09 根据二次验收进一步放慢追赶（第三人称频率 8.5、第一人称 12），放宽位移与角度限位，允许小幅停步回摆。接近边界时增强回拉并限制继续向外的速度，不再一触边界就清空所有运动。外侧硬限位与异常重置仍保留。第一人称比第三人称更稳，避免物品大幅扫过视野。

使用物品时幅度收紧到 22%，加快回正且不生成尾迹。睡眠、乘骑、不可见/死亡、非魔法路径不产生新的惯性或拖尾。地图和望远镜等特殊第一人称路径不添加普通物品弹簧；地图仅适配空手收放的尺寸渐变与原版显示物品交接，见《魔法收放物品》。悬停使用按玩家和手错相的三轴复合波形，不恢复旧版单一周期摆动；随游戏时钟推进，暂停不漂移，使用物品时关闭。根据追加验收要求，仅将上下悬停分量提高至上一版的 5 倍（系数 0.095 → 0.475），第三人称理论最大上下偏移 0.171 格，第一人称 0.07125 格；水平幅度、频率、惯性参数不变，叠加运动后仍受原有垂直硬限位约束。

实际水平移动超过 0.6 格/秒即产生光带，不再要求冲刺。普通移动使用上一版长度的 75%、峰值透明度的 80%（0.224）；冲刺时按实际速度从 4.3 至 5.6 格/秒平滑增强至上一版长度的 2 倍、宽度的 1.5 倍，峰值透明度仍为 0.28。状态过渡使用 0.18 秒响应时间；停止后保留已有世界轨迹自然淡出，不跟随原地悬停，也不突然缩短或缩窄。长度、宽度是名义几何值，柔边、渐细与寿命淡出会降低实际可见覆盖。

历史点保存世界坐标；尾端在长度上限处插值裁切，高速运动不会因为一段过长而整段消失。寿命增加时自动降低采样密度，仍限定 24 个轨迹点。渲染宽度通过 `entry.motion.trailWidth()` 获取当前平滑状态，不直接读取 Profile 基准宽度。尾迹头在 `ItemAuraGeometry` 捕获完物品显示变换后取真实几何中心，避免不同工具/方块的偏心模型错位。

拖尾使用 `horn_aura` shader 的独立 `effect=3` 分支，角、星星和物品剪影的原 0/1/2 分支不变。光带保留渐细淡出，沿视轴观察时补少量柔光截面，不添加完整物品残影。沿已有 `HornAuraPass` 延后绘制：世界普通模式只写颜色，Fabulous 写独立实体目标的排序深度；第一人称在两只手的原物品完成后绘制，不混用世界投影。捏脸预览不参与运动状态。

## 验证与边界

2026-09-09 使用缓存依赖局部 `javac --release 17`，回归运动/帧率/生命周期/高速尾迹、偏心几何/坐标基底、原有物品轮廓和隐藏 GPU shader/遮挡测试；不运行 Gradle，不启动 Minecraft。

本轮新增普通移动、冲刺切换、停步淡出、增强惯性和第一人称范围检查，覆盖 30/60/144 FPS；正式观感仍待用户在游戏验收。重点验收跑停、落地、快速转身的回摆，以及正后方和第一人称拖尾遮挡；多人视觉由各客户端用已同步的玩家移动自行重建，允许非常轻微的时间差。
