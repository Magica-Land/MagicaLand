# 自动眼仁注视

只移动眼仁，不转动头部、镜头，不自动改变表情。默认启用；可在模组设置的游戏页关闭“眼仁自动注视”。这是本客户端的显示开关，适用于本机看到的小马，不改变其他客户端的设置。

## 目标规则

固定优先级：最近攻击过自己的实体 → 敌对实体 → 其他玩家 → 中立生物 → 友善生物。同级选最近；只有距离差不足 0.2 格时保留原目标，避免反复切换。更高优先级不受该缓冲限制。

- 范围为玩家位置到实体位置的三维球形距离 8 格，含边界，不是 8 格搜索方框。
- 最近攻击者使用原版记录的最后一个攻击者，优先权保留 100 tick（正常 TPS 下 5 秒）。记录过期后按该实体普通分类处理。
- 只考虑活着的玩家和生物，不看自己、旁观者、盔甲架、掉落物、经验球。睡眠、死亡、旁观状态的小马不选目标。
- 隐身实体一律排除，即使同队或有其他显示效果也不作为目标。另检查针对该玩家的不可见状态。
- 从被渲染玩家的原版眼部位置到目标眼部位置做方块视线检测；有遮挡就排除，不穿墙追踪。使用原版 `VISUAL` 射线形状，忽略液体。其他可见生物用碰撞箱检查遮挡；这是保守的眼部射线判定，不是像素级外形遮挡分析。
- 搜索限定在玩家头朝向左右各 100° 的前侧区域，正后方不追踪；最终眼仁仍受模型实际朝向和安全幅度约束。不是读取第三人称摄像机的画面。
- 中立生物明确以自己为攻击目标、或对自己愤怒时提升到敌对。兼顾普通攻击目标与 Brain 的 `ATTACK_TARGET` 记忆。

默认中立分类涵盖原版 `Angerable` 生物及猪灵、山羊、羊驼、行商羊驼、熊猫、海豚。其余带 `Monster` 标记的生物归敌对；其余生物归友善。蜘蛛按敌对类别处理，不额外预测白天、亮度等情境。第三方生物可能需要补充分类。

可用数据包扩展 `magicaland:gaze_hostile`、`magicaland:gaze_neutral`、`magicaland:gaze_friendly` 三个实体类型标签。最近攻击者、已确认针对自己的攻击状态优先；显式敌对标签高于友善和中立标签，友善标签可覆盖默认类别。不要同时把同一类型加入多个标签。

## 表情与移动

`assets/magicaland/expressions.json` 的表情定义增加 `gaze`：

- `auto`：允许自动注视。当前只有普通表情启用，因此使用普通眼的动作可以注视。
- `locked`：保留作者编排的眼神。向后看、向下看、下落过渡、挥手、芭蕾使用此模式。
- `off`：不添加自动眼仁移动。现有笑眼、闭眼、挤眼及独立生气眼型使用此模式。

未填写 `gaze` 的旧资源包默认锁定，避免覆盖作者眼神。一个动作引用先播后循环的两个表情时，两者都允许才会启用；因此当前下落过渡动作整段让位于原演出。修改映射不必编辑身体动画。

每个 `eye_styles` 条目增加 `gaze_limits`，单位为模型像素：

| 眼型 | 左眼向外 | 右眼向外 | 向上 | 向下 |
| --- | ---: | ---: | ---: | ---: |
| 01 | 0.94 | 0.94 | 0.18 | 0.46 |
| 02 | 0.94 | 0.94 | 0.42 | 0.46 |
| 03 | 0.68 | 0.78 | 0.24 | 0.46 |

左右眼以角色的 `left_pupil`／`right_pupil` 骨骼为准，不是观察者屏幕上的左右。默认眼仁已靠近鼻梁，因此水平只移动朝目标外侧的那只眼仁，另一只不继续向鼻梁挤；垂直方向允许两眼一起看，但分别计算安全幅度。03 的斜眼框与原始两眼几何不完全对称，使用独立上限。

水平与垂直合用椭圆限位，不在对角线叠出过大位移。每个眼型可在 `gaze_limits` 中增加 `left`／`right`，分别填写 `outward`、`up`、`down`；省略时继承该眼型的通用上限，不需要增加动画轨道。非法或超过通用上限的配置会被拒绝。

数值是眼仁原始大小时的上限。眨眼回弹使眼仁变大时，根据当前眼仁 cube 顶点与缩放轴心，逐眼扣除增长的边缘余量；不缩小或改写原本的眨眼。当前眼仁 cube 没有局部旋转，新增旋转式眼仁需要重新验收。保留原缩放、旋转与深度，不改变模型、UV、纹理、Blockbench 项目或动画关键帧。

方向响应在水平约 45°、垂直约 22° 达到满幅（斜向仍受椭圆约束），比第一版更容易看出上下移动。01 眼仁本身较高，上方空间很小，保留 0.18 的向上上限，不通过强行越过上眼框扩大幅度。

注视方向通过实际渲染矩阵换算，包含身体转向、头部动画和飞行侧倾。只在世界中的玩家模型渲染时启用；标题、捏马预览不追踪世界实体。平滑按游戏时间推进，不按渲染次数推进；目标丢失后缓慢回正。临时骨骼状态在面部绘制结束后恢复，异常退出亦恢复。

## 联机与性能

支持新版服务端时由服务端选目标，客户端再次检查范围、隐身与视线，再渲染眼仁。不接受客户端指定攻击者或注视目标。每 5 tick 重选目标，按优先顺序验证候选视线，找到可用目标即停止；每 tick 验证已有目标。目标变化发送消息，每 40 tick 补发一次。消息只含源玩家、维度、目标实体 ID 与 UUID，不逐帧发送坐标。

目标消息通过独立的 `magicaland:gaze_v1` 服务端单向通道发送给自己，以及正在追踪该玩家且支持该通道的客户端。关闭外观广播时仍能得到自己的服务端判定，但不向其他玩家广播自己的注视状态。客户端验证 ID 与 UUID 同时吻合，避免实体 ID 复用导致看错人；切换世界、断线及过期消息会清理状态。

旧版／未安装模组的服务端不具备准确的攻击者和仇恨同步，降级为客户端基于可见实体的分类与距离选择；中立实体是否正在针对自己、最近攻击者可能无法准确判定。客户端保留原版中立类型回退，不依赖旧服务端提供新增标签。不要把降级模式当成准确仇恨判断。

## 离线验证

首次离线阶段使用现有缓存依赖，对 19 个相关 Java 源码／测试文件作 Java 17 独立类型检查；该阶段没有启动游戏。随后按用户授权完成下述实际游戏验收。

- `GazePolicyTest`：1032 项断言，覆盖优先级、距离、时间窗、缓冲切换、视角、遮挡候选回退和无目标恢复。
- `GazeMessageTest`：65 项断言，覆盖目标／清空消息往返、截断、非法实体 ID、维度长度和多余数据拒绝。
- `PonyGazeMathTest`：4512 项断言，覆盖左右／上下方向、任意变换、退化矩阵、椭圆限位、帧率独立与时间回退。
- `PonyFacePoseTest`：9677 项断言，覆盖原表情维修及三眼型注视限位、仅 XY 移动、原缩放保留、异常恢复和资源配置校验。

### 待解决：传送后的远端身体朝向差异

快速移动／卸载再进入追踪后，访客本地 `bodyYaw=180°`，主机观察该访客时 `bodyYaw=-130°`，等效差 50°；两端头朝向均约 180°，目标均为主机。因为现有小马整体按 `bodyYaw` 旋转，这时主机看到的是侧身，眼仁投影回中；访客自己仍看到侧向注视。截图与数值均复现，不是目标消息选错人。

仅在诊断控制组将两端身体朝向对齐后，眼仁数值及画面恢复一致。对齐逻辑只在测试辅助模组中，未进入正式代码；不能拿控制组代替自然转向的联机验收。现有按 `bodyYaw` 旋转的实现也存在于加入自动注视前的提交中，但尚未用旧版双开复现，因此目前只能判定它暴露了既有朝向路径的问题，不能证明所有触发条件都与本次改动无关。正常步行与手动转身的复现率仍待补验。

- [ ] 先用自然移动、转身和传送区分本地强制摆姿与原版远端身体插值的影响，再决定是否修正身体／头部朝向基准。不要直接强制两端整体同向，也不要通过新增动作补偿掩盖。
